`strokes.js` contains only the ordered stroke paths needed for this CASE's question.
Source: [KanjiVG](https://kanjivg.tagaini.net/), Copyright (C) 2009/2010/2011 Ulrich Apel.
The local SVG copyright headers state these years.

The extraction removes SVG wrappers, component metadata and stroke-number labels;
path coordinates and stroke order are preserved. Punctuation paths are original
additions and are distributed under the same license as the data file.
